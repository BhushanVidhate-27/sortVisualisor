

# 🔢 Sorting Algorithm Visualizer

An interactive **Sorting Visualizer** built using **HTML, CSS, and JavaScript** to help understand how different sorting algorithms work through animations.

---

## 🚀 Features
- 📊 Visual representation of sorting algorithms
- 🔀 Random array / shuffle generation
- 🧠 Multiple sorting algorithms
- 🎯 Clean and responsive UI

---

## 📂 Project Structure
```
sortVisualizer/
│── index.html        # Main UI
│── style.css         # Styling
│── layout.css        # Layout design
│── app.js            # Core logic
│── sortAlgo/         # Sorting algorithms
```

---

## 📊 Algorithms Included
- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort
- Radix Sort
- Odd-Even
- Shaker Sort
- counting sort
- pancake sort
- Gnome sort

---

## ⚙️ How to Run
1. Clone the repository:
   ```
   git clone https://github.com/BhushanVidhate-27/sortVisualisor.git
   ```
2. Navigate to the folder
3. Open `index.html` in your browser

---

## 🎮 Usage
- Click **Add Candles / Generate** to create bars
- click suffle to cahne order
- Choose a sorting algorithm
- Watch the sorting process visually 🎉
