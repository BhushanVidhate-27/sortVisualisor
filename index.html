Featured Sorting Algorithms

Quick Sort

O(n log n)

Divide-and-conquer. Partitions the array around a pivot element so left elements are smaller and right elements are larger.

Merge Sort

O(n log n)

Stable divide-and-conquer. Recursively splits the array in half, sorts each half, and merges the sorted halves back together.

Heap Sort

O(n log n)

In-place binary heap. Moves array values into a Max-Heap structure and repeatedly extracts the root maximum value.

Insertion Sort

O(n²)

Incremental construction. Inserts each unsorted element step-by-step into its proper sorted position relative to previous values.

Bubble Sort

O(n²)

Adjacent swaps. Iterates through the elements, swapping adjacent elements if they are out of order, bubbling max values to the end.

Counting Sort

O(n + k)

Non-comparison sorting. Counts occurrences of each unique element and determines index placement mathematically.
